# Ellen Joe Pixel v0.1.2

This public-readiness release adds bilingual documentation, an explicit rights
and provenance record, and complete notices inside the downloadable archives.
It is an unofficial, non-commercial fan project and is not affiliated with,
endorsed by, or sponsored by HoYoverse/Cognosphere or OpenAI.

## What changed

- Added a full Simplified Chinese guide alongside the English README.
- Added a scoped MIT License for original source code and original written
  documentation only.
- Added public fan-work, third-party, provenance, and study-reference notices.
- Included `README.zh-CN.md`, `LICENSE`, and `THIRD_PARTY_NOTICES.md` in both
  release archive formats.
- Updated historical release notes and internal production records for public
  repository context.

## Compatibility

The Codex v2 package, `192 x 208` frame cells, animation manifest, installers,
and supported Windows, macOS, and Ubuntu-tested Linux paths are unchanged from

## Rights and provenance

Public availability does not change the rights boundary. The
[MIT License](../../LICENSE) covers only original source code and original
written documentation. Artwork, character elements, official references, QA
media derived from the artwork, and other third-party material remain excluded
under [NOTICE.md](../../NOTICE.md) and
[THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md).

The following repositories were studied as references only:
