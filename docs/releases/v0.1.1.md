# Ellen Joe Codex Pet v0.1.1

This patch fixes duplicate Ellen Joe entries after a forced reinstall.

## Fixed

- Forced-install backups now live under `<CodexHome>/pet-backups` instead of
  `<CodexHome>/pets`, so Codex does not discover a backup as a second pet.
- Failed installs still restore the previous pet when rollback succeeds.
- Uninstall still removes only the active `ellen-joe-pixel` package and keeps
  its backups intact.

The sprite atlas, animation manifest, and supported Windows, macOS, and Linux
install paths are unchanged from v0.1.0.

This is a private, unofficial fan project. Character rights belong to their
respective owners.
