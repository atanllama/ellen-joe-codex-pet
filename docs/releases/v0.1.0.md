# Ellen Joe Pixel v0.1.0

This is the first private release of the Ellen Joe Pixel Codex Pet. It is an
unofficial, non-commercial fan project for Boss's personal use. The project is
not an official Zenless Zone Zero or Ellen Joe release; see [NOTICE.md](../../NOTICE.md).

## What is included

The package uses Codex sprite version 2, with `192 x 208` cells in an exact
`1536 x 2288` 8-column x 11-row atlas. The complete animation set is:

- `idle`
- `running-right`
- `running-left`
- `waving`
- `jumping`
- `failed`
- `waiting`
- `running`
- `review`
- the 16-direction look loop: `000`, `022.5`, `045`, `067.5`, `090`, `112.5`,
  `135`, `157.5`, `180`, `202.5`, `225`, `247.5`, `270`, `292.5`, `315`,
  `337.5`

Look directions are in clockwise screen coordinates: `000` is up, `090` is
screen-right, `180` is down, and `270` is screen-left. The loop is split across
the two final atlas rows and includes the reviewed `157.5 -> 180` and
`337.5 -> 000` boundaries.

## Platforms and safety

Installation is supported on Windows PowerShell, macOS, and Linux. The package
has platform-specific PowerShell and POSIX installers, explicit Codex-home
overrides, duplicate-install protection, exact-target replacement, timestamped
backups, and rollback-aware exit codes. The installer never replaces a target
without an explicit `-Force`/`--force`. See the exit-code table in
[README.md](../../README.md).

## Release artifacts

The release workflow produces exactly these files:

- `ellen-joe-pixel-v0.1.0.zip`
- `ellen-joe-pixel-v0.1.0.tar.gz`
- `SHA256SUMS.txt`

Each archive contains the package manifest, WebP atlas, four installers,
`README.md`, and `NOTICE.md`. `SHA256SUMS.txt` is the checksum authority for
the two archives. The `main` push/pull-request `validate.yml` workflow is the
three-platform matrix for Windows, macOS, and Ubuntu; Task 12 requires that
matrix to pass before tag `v0.1.0` is pushed. The tag-triggered `release.yml`
workflow then reruns its package and POSIX installer gates, builds the archives
and checksums, copies these notes, and creates the private GitHub Release only
after those tag-run checks pass. The tag workflow is therefore a second
release gate, not a replacement for the pre-tag three-platform matrix.

## Validation record

The final v2 atlas passed the package contract and independent final visual QA.
The curated evidence records the v2 validator, continuity and direction
semantics, three isolated blind reviews, the accepted labeled warnings, and the
single completed-atlas chroma-edge despill. The final visual result is
`visual_qa=pass`.
